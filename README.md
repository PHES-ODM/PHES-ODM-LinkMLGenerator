# <img src="img/ODM-logo.png" align="right" alt="" width="180"/> PHES-ODM LinkML Schema Generator

This repository contains code to generate the LinkML schemas for The Public Health Environmental Surveillance Open Data Model (PHES-ODM). It includes code to generate schemas for both versions 1 and 2 of the PHES-ODM. [LinkML Schemasheets](https://github.com/linkml/schemasheets) is used to create the schemas by using various files generated by or included in this repository.

Note that the final LinkML schemas generated by running the code is included in this repository. Running the code will overwrite these outputs. ODM v1 is located at [odm_v1/linkml/odm_v1.yaml](odm_v1/linkml/odm_v1.yaml) and ODM v2 is located at [odm_v2/linkml/odm_v2.yaml](odm_v2/linkml/odm_v2.yaml).

## Installation

To install the repository and all dependencies, execute the following:

```console
git clone git@github.com:Big-Life-Lab/PHES-ODM-LinkMLGenerator.git
pip3 install -r PHES-ODM-LinkMLGenerator/requirements.txt
```

## Generating the ODM v1 LinkML Schema

Generation of the ODM v1 schema is fairly simple and is not expected to change much in the future. The Schemasheets for ODM v1 have already been created and included in this repo, they are located at [odm_v1/schemasheets](odm_v1/schemasheets). All that is required is to run Schemasheets on these files. This can be done by running the script `make_v1.py`:

```console
cd src
python3 make_v1.py
```

The script will output the location of the saved schema. By default this is located at "odm_v1/linkml/odm_v1.yaml".

## Generating the ODM v2 LinkML Schema

Since ODM v2 is a much more complex data model and is expected to have some ammendments in the future, generation of the ODM v2 schema is more complicated and involves a lot of processing of the ODM v2 data dictionary spreadsheet to create a series of Schemasheets. We have included a single script that can be run to do the full processing and generation of the final LinkML schema.

Before generating the schema, you must first obtain the Excel data dictionary for the ODM. This file is currently not publicly available. To obtain the file please contact [Mathew Thomson](mailto:matthomson@ohri.ca). Once you obtain the data dictionary, save it as "v2 ODM dictionary.xlsx" in the "odm_v2" root directory. Since this spreadsheet uses several Excel functions not supported in some older versions of Excel (such as the FILTER and XLOOKUP functions), it is recommended that you do not load and resave the file in Excel, as doing so will make the file unusable.

Once the Data Dictionary has been put in place, execute the following to generate the LinkML schema:

```console
cd src
python3 make_v2.py
```

The final LinkML schema will be saved at "odm_v2/linkml/odm_v2.yaml".

If you would like more details of what this script does (as well as all the other scripts referenced by make_v2.py), a description of the processing steps performed by `make_v2.py` can be found in [Generating the ODM v2 LinkML Schema](make_v2.md).
