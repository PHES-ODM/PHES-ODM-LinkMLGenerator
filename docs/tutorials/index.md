# Tutorials

Tutorials are lessons. They take you by the hand through a sequence of steps and
end with something that works, so that you learn how the project fits together
by using it. They are not the shortest route to a result and they do not cover
every option — that is what the [how-to guides](../how-to/index.md) are for.

Work through them in order.

1. **[Generate your first schema](generate-your-first-schema.md)** — install the
   package, generate the ODM v1 LinkML schema, and read the files it produces.
   Needs nothing but a Python install.

2. **[Generate an NWSS schema](generate-an-nwss-schema.md)** — download a public
   CDC dictionary and run the full three-stage pipeline over it, watching each
   stage's output appear on disk.

Once both make sense, the [explanation](../explanation/index.md) section
describes why the pipeline is shaped the way it is.
